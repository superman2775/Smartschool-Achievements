# Security Policy

## Supported Versions

Only report about the latest beta version, or release.

| Version | Supported          |
| ------- | ------------------ |
|Release  | :white_check_mark: |
|Beta     | :white_check_mark: |
|Random Branch   | :x: |

## Reporting a Vulnerability

If you find a vulnerability, post it in issues, and tell us more. You can also make a PR.
